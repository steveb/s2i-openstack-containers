# edpm-hardened-uefi package inventory for container-based image builds.
#
# This file lists the RPM packages installed into the root filesystem that
# the diskimage-builder appliance starts from (DIB_TARBALL_PATH). The
# os_source stage installs this list and also collects the RPMs behind it,
# plus their full dependency closure, into a local repository that ships
# inside the os_source tarball. During the in-VM diskimage-builder run that
# repository is the only one visible to dnf, so package requests made by
# diskimage-builder elements are installed from the frozen package set.
#
# The list is derived from the elements in edpm-s2i.yaml and from the
# CentOS Stream GenericCloud base that the reference edpm-hardened-uefi
# image starts from:
#   - edpm-image-builder: edpm-base, edpm-partition-uefi, interface-names,
#     openvswitch, cloud-init-network-renderer, reset-bls-entries
#   - diskimage-builder: bootloader, grub2, dracut-regenerate, cloud-init,
#     stable-interface-names, redhat-common, growvols
#
# Included packages are installed, so entries that edpm-base uninstalls
# (kexec-tools, telnet) are listed to mirror the reference image.
#
# TODO: reconcile this inventory against a reference edpm-hardened-uefi
# qcow2 (rpm -qa) when one is available.
